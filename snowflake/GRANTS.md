# Granting roles 
```sql
GRANT ROLE NON_PII_ROLE TO USER "DYMYTRYO@ME.COM";
GRANT ROLE     PII_ROLE TO USER "DYMYTRYO@ME.COM";
```

```sql
-- Exposing to the other service account
GRANT USAGE ON DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
GRANT USAGE ON ALL SCHEMAS IN DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
GRANT SELECT ON ALL TABLES IN DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
GRANT SELECT ON ALL VIEWS IN DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
GRANT SELECT ON FUTURE TABLES IN DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
GRANT SELECT ON FUTURE VIEWS IN DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
GRANT USAGE ON FUTURE SCHEMAS IN DATABASE DATA_LAKE TO ROLE STARBURST_ROLE;
```

```sql
-- Exposing to the users
GRANT USAGE ON SCHEMA DATA_WAREHOUSE.SALESFORCE_REP TO ROLE DEV_ROLE;
GRANT SELECT ON ALL TABLES IN SCHEMA DATA_WAREHOUSE.SALESFORCE_REP TO ROLE DEV_ROLE;
GRANT SELECT ON ALL VIEWS IN SCHEMA DATA_WAREHOUSE.SALESFORCE_REP TO ROLE DEV_ROLE;
GRANT SELECT ON FUTURE TABLES IN SCHEMA DATA_WAREHOUSE.SALESFORCE TO ROLE DEV_ROLE;
GRANT SELECT ON FUTURE VIEWS IN SCHEMA DATA_WAREHOUSE.SALESFORCE TO ROLE DEV_ROLE;
```

# Rewoking roles 
`USAGE` allows seeing that the schema exists and use the schema.
```sql
REVOKE USAGE ON SCHEMA DATA_LAKE._kafkaspend FROM ROLE STARBURST_ROLE;
```

-- This will affect current tables (since the grant gave access on future tables as well
```sql
REVOKE SELECT ON ALL TABLES IN SCHEMA DATA_LAKE._kafkaspend FROM ROLE STARBURST_ROLE;
REVOKE SELECT ON ALL VIEWS IN SCHEMA DATA_LAKE._kafkaspend FROM ROLE STARBURST_ROLE;
```
Revoke access on fugure tables 
```sql
REVOKE SELECT ON FUTURE TABLES IN SCHEMA DATA_LAKE._kafkaspend FROM ROLE STARBURST_ROLE;
REVOKE SELECT ON FUTURE VIEWS IN SCHEMA DATA_LAKE._kafkaspend FROM ROLE STARBURST_ROLE;

```
