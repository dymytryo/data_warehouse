# Check grants 
Check grants for a specific user:
- `USAGE` -> you can kick-off queries 
- `OPERATE` -> you can only manage jobs, but not start them
~~~sql
SELECT DISTINCT
  gr.name         AS warehouse,
  gr.grantee_name AS via_role, gr.privilege
FROM
  SNOWFLAKE.ACCOUNT_USAGE.GRANTS_TO_ROLES gr
WHERE
  True
  AND gr.granted_on='WAREHOUSE'
  AND gr.privilege IN ('USAGE','OPERATE')
  AND gr.deleted_on IS NULL
  AND gr.grantee_name IN (SELECT role
                          FROM SNOWFLAKE.ACCOUNT_USAGE.GRANTS_TO_USERS
                          WHERE grantee_name = 'DBT_PROD' AND deleted_on IS NULL);
~~~
Check all warehouses available:
~~~sql
SHOW WAREHOUSES;
~~~
Check the account level or a specific warehouse level:
~~~sql
SHOW PARAMETERS LIKE 'STATEMENT_TIMEOUT_IN_SECONDS' IN ACCOUNT;
-- → value 172800, level '' (default)                     = 48h

SHOW PARAMETERS LIKE 'STATEMENT_TIMEOUT_IN_SECONDS' IN WAREHOUSE DEV;
-- → value 172800, level '' (default)                     = 48h  
~~~

# Snowflake role grants

Patterns for granting and revoking access during a migration.

~~~sql
GRANT ROLE ANALYST_ROLE TO USER EXAMPLE_USER;

GRANT USAGE ON DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
GRANT USAGE ON ALL SCHEMAS IN DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
GRANT SELECT ON ALL TABLES IN DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
GRANT SELECT ON ALL VIEWS IN DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
GRANT SELECT ON FUTURE TABLES IN DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
GRANT SELECT ON FUTURE VIEWS IN DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
GRANT USAGE ON FUTURE SCHEMAS IN DATABASE SOURCE_DATA TO ROLE SERVICE_ROLE;
~~~

USAGE permits the role to resolve a database or schema. Object privileges such
as SELECT must still be granted separately.

~~~sql
REVOKE SELECT ON ALL TABLES
    IN SCHEMA SOURCE_DATA.RETIRED_DOMAIN
    FROM ROLE SERVICE_ROLE;
REVOKE SELECT ON ALL VIEWS
    IN SCHEMA SOURCE_DATA.RETIRED_DOMAIN
    FROM ROLE SERVICE_ROLE;
REVOKE SELECT ON FUTURE TABLES
    IN SCHEMA SOURCE_DATA.RETIRED_DOMAIN
    FROM ROLE SERVICE_ROLE;
REVOKE SELECT ON FUTURE VIEWS
    IN SCHEMA SOURCE_DATA.RETIRED_DOMAIN
    FROM ROLE SERVICE_ROLE;
REVOKE USAGE ON SCHEMA SOURCE_DATA.RETIRED_DOMAIN
    FROM ROLE SERVICE_ROLE;
~~~
